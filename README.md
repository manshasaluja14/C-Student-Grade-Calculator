# C Student Grade Calculator

## Aim
To create a C program that calculates a student's total marks, percentage and grade.

## Features
- Takes student name
- Takes marks of three subjects
- Calculates total marks
- Calculates percentage
- Displays grade

## Technology Used
- C
- VS Code

## How to Run

Compile:

gcc StudentGradeCalculator.c -o StudentGradeCalculator

Run:

StudentGradeCalculator
